# Électroportatif

Inventaire du matériel électroportatif, consultable sur téléphone.

- **Page :** https://alexislanon-collab.github.io/electroportatif/
- **Données :** `materiel.json` (une ligne par matériel). Chaque publication depuis le mode admin crée un commit, donc tout l'historique est conservé ici.
- **QR code à imprimer :** `qr-code.png`

## Mode admin
Bouton **Admin** sur la page, puis coller une clé GitHub (fine-grained token) limitée à ce dépôt avec la permission *Contents : Read and write*. La clé reste sur le téléphone de l'admin.
